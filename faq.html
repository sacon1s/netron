FAQ

Everything you might want to know about temporary email.

What is NETRON?

NETRON is a free disposable email service. It gives you a temporary address that receives mail just like a normal inbox — but self-destructs after 60 minutes, keeping your real email safe from spam and leaks.

How long does the mailbox live?

60 minutes from generation. The countdown is shown as a ring above the address. Receiving new mail extends the lifetime, so an actively used inbox survives longer.

Can I send email from NETRON?

No. NETRON is receive-only — that's a deliberate design choice that keeps the service anonymous and abuse-free.

I'm waiting for a code but nothing arrives. Why?

A few possible reasons:

1. Some services block known disposable domains outright — there's nothing any temp-mail service can do about that.
2. Delivery can take a minute or two, especially with bulk senders.
3. Check that the address was copied in full — the QR button is handy here.

If all else fails, generate a new address (you can pick a custom name) and try again.

Can I choose my own address name?

Yes — open “Customize address” above the Generate button, type your name (3–29 characters: latin letters, digits, dots, dashes) and hit Generate. If the name is taken, pick another one.

Is NETRON really private?

NETRON itself collects nothing: it's a static site with no backend. Your browser talks straight to the Guerrilla Mail API that hosts the mailboxes; favorites and your session live in your browser's local storage only. The usual temp-mail caveat applies — never use disposable mail for anything sensitive, since anyone who knows the address could potentially read it while it's alive.

Should I use it for important accounts?

No. The mailbox is destroyed after 60 minutes. If a service later sends a password-reset or security email, it will be gone. Use NETRON only for throwaway signups.

Can I recover an expired mailbox?

No. Expiration is permanent — that's the point. If you act fast you can generate a mailbox with the same custom name before someone else claims it, but old mail is unrecoverable.

Can I run several addresses at once?

NETRON tracks one active mailbox per browser tab session. If you need several, open the site in a second tab (or a private window) and generate another address there. Tip: copy each address somewhere before switching — generate with the same custom name to return to the same mailbox while it's still alive.

What are favorites?

Star any message to pin it to the Favorites tab for quick access while the mailbox lives. Favorites are stored locally in your browser and are cleared together with the session — they don't survive mailbox expiration.

Is it safe to open HTML emails?

NETRON sanitizes every message before rendering: scripts, frames, forms and event handlers are stripped, dangerous URLs are removed, and links are forced to open safely in a new tab. Still, treat unknown emails with the same caution as anywhere else.

Who provides the mailboxes?

The disposable mailboxes are provided by the public Guerrilla Mail API. NETRON is a lightweight, privacy-respecting client for it, served via GitHub Pages.
